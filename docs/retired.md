# Retired projects

(landmarker.io, which used to be listed here, is back: see [landmarker.io](landmarkerio/index.md).)

These projects are no longer maintained and are not part of the current Menpo Project.

## menpocli

A command line tool that applied pre-trained `menpofit` facial models. It is superseded by using `menpofit`
together with `menpodetect` directly; see the [MenpoFit guide](menpofit/index.md).

## menpobench

A benchmarking framework for deformable models. It is no longer developed.
