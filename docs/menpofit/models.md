# Every Model, Built and Fitted

One short example for each family of models in `menpofit`, how to build it and how to fit it, is kept next to the code in the user guide of
the `menpofit` documentation, where its examples are run by the package's own tests. That page covers the AAM family (holistic, patch, masked, linear),
ATM, CLM, the unified AAM and CLM, APS, supervised descent (`SupervisedDescentFitter`, `SDM`, `RegularizedSDM`), Lucas-Kanade, `DlibERT` and
saving and loading models.

[**Every Model, Built and Fitted**](https://menpofit.readthedocs.io/en/latest/userguide/models.html)

This website has a longer page, with the method and some theory, for each of the models: [AAM](aam.md), [ATM](atm.md), [APS](aps.md), [CLM](clm.md),
[SDM](sdm.md), [ERT](ert.md), [Lucas-Kanade](lk.md) and the [Point Distribution Model](pdm.md) they build on.
